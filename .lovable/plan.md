# Android 100×75 mm တိုက်ရိုက်စတစ်ကာပရင့်

## ရည်ရွယ်ချက်
Android ဖုန်း/Tablet မှ Print နှိပ်လျှင် စက်ချိတ်ဆက်ခွင့်နှင့် ပရင်တာကို ပထမတစ်ကြိမ် သတ်မှတ်ပြီးနောက် Printer ရွေးစရာ၊ Print Preview မပေါ်ဘဲ 100×75 mm လိပ်စာစတစ်ကာ ထုတ်ရန်။

## တည်ဆောက်မည့်အပိုင်း
- လက်ရှိ ရွေးထားသည့်အော်ဒါများ၏ အမည်၊ ဖုန်း၊ လိပ်စာ၊ ပစ္စည်းနှင့် အရေအတွက်ကို စတစ်ကာတစ်ရွက်စီ ထုတ်မည်။ အော်ဒါ၏ လုပ်ဆောင်ချက် လေးခုကို မပြောင်းပါ။
- 100×75 mm အရွယ်အစားကွက်တိ PDF Template ပြုလုပ်မည်။ မြန်မာစာကို မှန်ကန်စွာဖတ်နိုင်သော font ဖြင့် ပုံဖော်ပြီး စာသားရှည်လျှင် အရွယ်အစားညှိမည်။ မဆံ့သေးလျှင် စာသားကို တိတ်တဆိတ်ဖြတ်မချဘဲ သတိပေးမည်။
- ပရင်တာနှင့် ချိတ်ဆက်နည်းကို ပထမတစ်ကြိမ်သာ သတ်မှတ်မည်။ နောက်ပိုင်း Print သည် သတ်မှတ်ထားသည့်ပရင်တာသို့ တိုက်ရိုက်ပို့မည်။ ချိတ်ဆက်မှုပြတ်လျှင် အမှားပြမည်၊ အလိုအလျောက် Print Preview သို့ မပြောင်းပါ။

## Android အတွက် ရွေးမည့်နည်းလမ်း
ပရင်တာ Brand/Model နှင့် USB၊ Bluetooth၊ Wi-Fi မည်သည့်နည်းဖြင့်ချိတ်ဆက်မည်ဆိုသော အချက်အလက် မရသေးသဖြင့် နောက်ဆုံးနည်းလမ်းကို မသတ်မှတ်ရသေးပါ။

- **BLE ပရင်တာ:** ပရင်တာက လိုအပ်သော BLE/GATT ချိတ်ဆက်မှုကို ပံ့ပိုးပါက Android Chrome Web Bluetooth ဖြင့် ချိတ်မည်။ ပထမအကြိမ် ချိတ်ဆက်ခွင့်နှင့် ပရင်တာရွေးရန် လိုအပ်သည်။ ပြန်ချိတ်ဆက်ခွင့် လိုလာနိုင်သည်။
- **Classic Bluetooth / USB ပရင်တာ:** Android အတွက် ပရင်တာထုတ်လုပ်သူအက်ပ် သို့မဟုတ် တိုက်ရိုက်ပရင့်ပို့နိုင်သည့် compatible bridge ကို အသုံးပြုမည်။ Android Browser တစ်ခုတည်းဖြင့် Classic Bluetooth ကို မပို့နိုင်ပါ။ သီးခြား Android အက်ပ်လိုအပ်ပါက ထည့်သွင်းရမည့်အက်ပ်နှင့် ကုန်ကျစရိတ်ကို အရင်ဖော်ပြမည်။
- Chrome `--kiosk-printing` နှင့် desktop QZ Tray ကို Android အတွက် မသုံးပါ။ Web App က Browser လုံခြုံရေး Dialog များကို ကိုယ်တိုင်ပိတ်၍ မရပါ။

## နည်းပညာအချက်အလက်
- PDF စာမျက်နှာအရွယ်အစား 100×75 mm၊ margin 0၊ တစ်စောင်လျှင် တစ်မျက်နှာ သတ်မှတ်မည်။
- မြန်မာစာကို ပရင်တာ၏ built-in font အပေါ်မမှီဘဲ shaped bitmap အဖြစ်ပို့မည်။ TSPL ပံ့ပိုးသောပရင်တာဆိုလျှင် `SIZE 100 mm,75 mm` နှင့် bitmap command သုံးမည်။
- Model အလိုက် printable width၊ DPI၊ gap/black-mark sensing၊ BLE UUID၊ packet size နှင့် command set ကို စစ်မည်။ ESC/POS ပရင်တာတိုင်း 100 mm label ထုတ်နိုင်သည်ဟု မယူဆပါ။
- Browser transport ကို client-side သီးခြား module တွင်ထားပြီး လက်ရှိအော်ဒါနှင့် shipping စည်းမျဉ်းများ မပြောင်းပါ။

## စစ်ဆေးမည့်အချက်များ
- စာမျက်နှာတိုင်း 100×75 mm ဖြစ်မှု၊ မြန်မာစာရှည်/အမည်ရှည် မပြတ်မှုနှင့် ရွေးထားသည့်အော်ဒါအရေအတွက်အတိုင်း label ထွက်မှု စမ်းသပ်မည်။
- ချိတ်ဆက်မရခြင်းနှင့် ပရင့်ပို့ခြင်းအောင်မြင်မှုကို စမ်းသပ်မည်။
- တကယ့် Android နှင့် ပရင်တာဖြင့် တစ်ချက်နှိပ်ထုတ်ခြင်း၊ Dialog မပေါ်ခြင်းနှင့် စတစ်ကာအရွယ်အစားကို စမ်းပြီးမှ Silent Print အောင်မြင်ကြောင်း အတည်ပြုမည်။ Sandbox စမ်းသပ်မှုတစ်ခုတည်းဖြင့် ရုပ်ပိုင်းပရင့်ထွက်မှုကို အတည်မပြုပါ။

## လိုအပ်နေသေးသည့်အချက်
**ပရင်တာ Brand/Model နှင့် ချိတ်ဆက်နည်း** လိုအပ်သည်။ ဥပမာ `Xprinter XP-420B၊ Bluetooth` သို့မဟုတ် ပရင်တာ Model စာတန်း၏ ဓာတ်ပုံ။
